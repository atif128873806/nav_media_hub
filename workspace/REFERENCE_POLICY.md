# Client reference policy

Default interpretation: learn from selected aspects and create an original project-specific
solution. A link or “I like this website” does not authorize a clone or every feature shown.

## Classify the reference

Use one or more roles: `visual`, `structure`, `feature`, `ux`, `booking-flow`, `competitor`,
`explicit-requirement`. The final role requires an actual instruction and accepted scope.

Record source ID, URL/file, observed date, client rationale, aspects to learn from,
aspects to avoid, asset ownership/permission when known, and linked requirement IDs.
If the user only provided a link, register `needs-interpretation`; do not invent preferences.

## Study and translate

1. Read client instructions and approved requirements before opening the reference.
2. Observe relevant hierarchy, navigation, density, flows, responsive behavior, and states.
   Record only observations actually seen. If browsing is unavailable, mark inaccessible
   and use provided screenshots/text; never claim to have inspected a live page.
3. Create a short translation table: observed pattern, business value, proposed adaptation,
   evidence/requirement link, and status. Separate observed facts from design suggestions.
4. Use the project's own copy, brand, composition, and authorized assets. Do not reuse
   source code or copy website text/images without authorized provenance.
5. Keep attractive but unapproved features in suggestions, outside implementation scope.
6. Check the final UI against both the requested ideas and project-specific identity.

## Example

Client: “I like how quickly this salon lets customers choose a service.”
Observation: service selection appears before the time picker.
Proposal: a compact service-first booking flow, styled for our salon and its actual services.
Do not infer: matching colors/logo, copied photos/text, loyalty points, a new mobile app,
mandatory sign-in, or every payment method offered by the reference.

## Exact-copy requests

If the user explicitly asks for exact reproduction, record exactly which layout/aspects
are authorized and which assets they own or permit. Resolve material uncertainties.
Do not change inspiration into exact reproduction merely because it would be easier.
