# Upstream skills and workspace authority

V1.3 combines 14 project/workflow procedures with four adapted official-source skills:
Vercel React performance, Vercel composition, Vercel web interface review, and Laravel
best practices. The entry point is ours; upstream instructions/rules are retained in
references/upstream/. Six Laravel template rules are rendered for generic local commands;
original templates remain available. The Vercel review uses a separately pinned rule snapshot.

Read workspace/upstream-lock.yaml for repository/revision/source path and reviewed date.
Each imported skill has provenance.json with original/rendered file checksums. Licenses
and upstream author metadata are retained. Do not describe these as entirely original
Atif skills or as guaranteed to improve every project.

## Selection and authority

Read accepted project context before selecting skills. Use official rule detail for
specialist engineering/review; use project rules for scope, identity, architecture, client
requirements, and allowed actions. Do not activate React procedures for plain PHP/Blade
or Next.js APIs for a React-only app. Match APIs to installed versions. Project-generated
Boost/package documentation takes priority for version-specific details; reconcile any
material conflict rather than guessing. Local entry wrappers enforce scope and reference
rules when the agent reads them; they are not a runtime sandbox.

## Updates

1. Resolve an official source revision; inspect differences and license/author metadata.
2. Preserve accepted project decisions and existing implementation conventions.
3. Copy/review the selected source files and regenerate only documented portable adapters.
4. Update per-file provenance and lock revision/hash together. Never edit an upstream rule
   silently while keeping its old checksum/revision.
5. Validate pointers and integrity, then test behavior on representative project tasks.
6. Replace native copies deliberately. Do not auto-update to latest during ordinary work.

No network installer, shell script, provider deployment skill, or dependency manager
command is executed by the bundled guidance. Optional native installation copies the
reviewed local skill directories only and refuses to overwrite existing installations.
No future Laravel app or MCP connection exists simply because its guidance is included.
