# Client Context Intake

Read workspace/CONTEXT_INTAKE.md, REFERENCE_POLICY.md, and AUTHORITY.md. Inspect the source
registry and approved project scope. Preserve originals, assign source IDs, and extract
atomic statements with timestamps/pages/sections. Keep proposals separate from accepted
scope. Compare old decisions and explicitly identify supersession/conflicts.

For references, record selected roles and client rationale. Translate observed patterns
into project-specific proposals; do not copy a full website or promote all visible features.
For unread attachments, use suitable tools or mark blocked. Never invent observations.
Update the context index, client brief, requirement/decision records, and accepted tasks.
Finish with a concise intake report of accepted facts, proposals, conflicts, and gaps.
