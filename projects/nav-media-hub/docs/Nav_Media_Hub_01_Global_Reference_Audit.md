## Cross-market patterns

1. **The most effective *presentation pattern* for this brief is specificity + proof + next step.** Industry examples, service descriptions and a contact action should be visible before a visitor has to interpret a long showreel. This is a qualitative design inference from the audited pages, not conversion test data.
2. **Film-studio sites often use near-black or charcoal and very large display type.** The product is the footage. A few strong frames do more work than many generic icons, gradient cards or vague promises.
3. **Booking means different things.** Some sites offer an immediate call slot, some ask for a project brief, and some invite a shoot request. Nav should name each action precisely. A discovery call is bookable only if connected to real availability; a shoot request remains pending until a producer confirms logistics and scope.
4. **Large-agency forms are often long.** Vidico's detailed form is a useful taxonomy reference, but a short hero form is more suitable to the demo; collect extended brief details after first contact.
5. **All-dark pages can hide the conversion path.** Nav can use a cinematic dark setting while giving the form a warm opaque panel and clear visual priority.

## Chosen design lineage

**Primary:** Rafhin's premium film presentation and Revline's disciplined contrast.  
**Secondary:** ByHadeed's editorial storytelling and selected work.  
**Conversion:** DBE's plain project language, with Lemonlight's inquiry-to-call sequence when calls are included.

The implementation must be an original Nav Media Hub design. Use no copied copy, photos, footage, logos, branded compositions, prices, reviews or claims from references.
