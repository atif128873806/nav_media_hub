# Workspace roadmap

1. Use V1.3 file workflow on real client tasks; identify missing context and quality gaps.
2. Add reliable context/routing tooling based on observed needs and explicit criteria.
3. Build a developer-focused UI with editor/chat, files, context, and terminal/Git/tests.
4. Design and implement a local execution service with real permission enforcement.
5. Add provider adapters and connected tools incrementally; test capabilities honestly.
6. Add durable source indexing, task tracking, and automations only when justified.

No runtime stack, queue, vector database, or multi-agent system is selected or delivered.
